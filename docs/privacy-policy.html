FastFit Extension - Privacy Policy

Last Updated: November 2025

Introduction

FastFit ("we", "our", or "us") is committed to protecting your privacy. This Privacy Policy explains how the FastFit Chrome Extension ("Extension") collects, uses, stores, and protects your information. By using the Extension, you agree to the collection and use of information in accordance with this policy.

Data Collection

The Extension collects the following types of data:

1. User Profile Data

  • User Photo: A photo you provide for virtual try-on generation (stored locally, encrypted)
  • Physical Measurements: Height (in cm), weight (in kg), and clothing sizes (top, waist, shoes, dress)
  • Country: Your country selection for sizing reference

2. Authentication Information

  • Gemini API Key: Your Google Gemini API key (stored locally, encrypted) - you provide your own key using the BYOK (Bring Your Own Key) model

3. Product Data

  • Product Images: Images extracted from Amazon product pages when you use the try-on feature
  • Product Metadata: Product title, category, and URL from Amazon pages

4. Generated Content

  • Try-On Images: AI-generated virtual try-on images (stored locally, optional - you can disable auto-save)

5. User Preferences

  • Display mode preferences (overlay or modal)
  • Auto-save settings for generated images
  • Confirmation dialog preferences

Data Storage

All data is stored locally in your browser. No data is transmitted to our servers.

The Extension uses the following local storage mechanisms:

  • Chrome Storage API: For encrypted user profile data and preferences
  • IndexedDB: For user photos and generated try-on images

All sensitive data (user profile, API key) is encrypted using browser-native encryption before storage. Your data remains on your device and is never uploaded to external servers.

Data Usage

The Extension uses collected data solely for the following purposes:

  • Virtual Try-On Generation: Your profile photo and measurements are combined with product images to generate personalized virtual try-on images
  • Product Information Extraction: Product data from Amazon pages is temporarily accessed to provide try-on functionality
  • API Calls: Your Gemini API key is used exclusively to make API calls to Google Gemini service for image generation
  • User Experience: Preferences are used to customize the Extension's behavior according to your settings

All data usage is directly related to the Extension's single purpose: enabling virtual try-on functionality for clothing items on Amazon.

Data Sharing and Third Parties

We do not sell, share, or transfer your data to any third parties.

The only external service interaction is:

  • Google Gemini API: When you use the try-on feature, the Extension sends your profile photo and product images to Google Gemini API using your own API key. This is the only external data transmission, and it occurs only when you explicitly trigger a try-on request.

We do not have access to your data, and we do not receive any data from Google Gemini. The API calls are made directly from your browser using your own API key.

Data Security

We implement the following security measures:

  • All sensitive data is encrypted before storage using browser-native Web Crypto API
  • Data is stored locally in your browser, not on external servers
  • No data is transmitted except when you explicitly use the try-on feature (to Google Gemini API)
  • You control your own API key and can revoke access at any time

Your Rights

You have full control over your data:

  • Access: You can view all stored data through the Extension's settings page
  • Modification: You can update your profile and preferences at any time
  • Deletion: You can delete all stored data at any time through the Extension's settings page using the "Clear All Data" option
  • Opt-Out: You can uninstall the Extension at any time, which will remove all locally stored data

Children's Privacy

The Extension is not intended for use by children under the age of 13. We do not knowingly collect personal information from children under 13. If you are a parent or guardian and believe your child has provided us with personal information, please contact us so we can delete such information.

Changes to This Privacy Policy

We may update this Privacy Policy from time to time. We will notify you of any changes by posting the new Privacy Policy on this page and updating the "Last Updated" date. You are advised to review this Privacy Policy periodically for any changes.
